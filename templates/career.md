# career.md

Copy this to `~/.claude/linkedin/career.md` and fill it in. The four `cv-*`
skills read it. `voice.md` is how you sound; this file is what is true about
you, and it is the only place a tailored resume is allowed to draw from.

---

## Never in the CV

Terms, tools or topics that must not appear in any tailored version, whatever
the job description asks. One per line. `cv-rewrite` will not add them and
`ats_check.py --never` fails the file if one slips in.
